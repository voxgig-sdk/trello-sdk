GET /boards/{boardId}/actions

Operation ID: get-boards-id-actions.

Authentication: API key in the query (APIKey) or API key in the query (APIToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | boardId | path | string | Yes | | | fields | query | object | No | The fields to be returned for the Actions. See Action fields here. | | filter | query | string | No | A comma-separated list of action types. | | format | query | string | No | The format of the returned Actions. Either list or count. | | idModels | query | string | No | A comma-separated list of idModels. Only actions related to these models will be returned. | | limit | query | number | No | The limit of the number of responses, between 0 and 1000. | | member | query | boolean | No | Whether to return the member object for each action. | | member_fields | query | string | No | The fields of the member to return. | | memberCreator | query | boolean | No | Whether to return the memberCreator object for each action. | | memberCreator_fields | query | string | No | The fields of the member creator to return | | page | query | number | No | The page of results for actions. | | reactions | query | boolean | No | Whether to show reactions on comments or not. | | before | query | string | No | A date string in the form of YYYY-MM-DDThh:mm:ssZ or a mongo object ID. Only objects created before this date will be returned. | | since | query | string | No | A date string in the form of YYYY-MM-DDThh:mm:ssZ or a mongo object ID. Only objects created since this date will be returned. |

Responses

200: Success

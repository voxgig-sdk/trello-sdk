| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string | Yes | The ID or name of the Organization | | name | query | string | No | A new name for the organization. Must be at least 1 character long and not begin or end with a space. | | desc | query | string | No | A new description for the organization | | website | query | string | No | A URL starting with http://, https://, or null | | prefs/associatedDomain | query | string | No | The Google Apps domain to link this org to. | | prefs/externalMembersDisabled | query | boolean | No | Whether non-workspace members can be added to boards inside the Workspace | | prefs/googleAppsVersion | query | integer (int32) | No | 1 or 2 | | prefs/boardVisibilityRestrict/org | query | string | No | Who on the Workspace can make Workspace visible boards. One of admin, none, org | | prefs/boardVisibilityRestrict/private | query | string | No | Who can make private boards. One of: admin, none, org | | prefs/boardVisibilityRestrict/public | query | string | No | Who on the Workspace can make public boards. One of: admin, none, org | | prefs/orgInviteRestrict | query | string | No | An email address with optional wildcard characters. (for example subdomain.*.trello.com) | | prefs/permissionLevel | query | string | No | Whether the Workspace page is publicly visible. One of: private, public |

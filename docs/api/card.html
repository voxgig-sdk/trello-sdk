Operation ID: post-cards.

Authentication: API key in the query (APIKey) or API key in the query (APIToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | name | query | string | No | The name for the card | | desc | query | string | No | The description for the card | | pos | query | enum: top, bottom or number (float) | No | The position of the new card. top, bottom, or a positive float | | due | query | string (date) | No | A due date for the card | | start | query | string (date) | No | The start date of a card, or null | | dueComplete | query | boolean | No | Whether the status of the card is complete | | idList | query | string | Yes | The ID of the list the card should be created in | | idMembers | query | array of string | No | Comma-separated list of member IDs to add to the card | | idLabels | query | array of string | No | Comma-separated list of label IDs to add to the card | | urlSource | query | string (url) | No | A URL starting with http:// or https://. The URL will be attached to the card upon creation. | | fileSource | query | string (binary) | No | | | mimeType | query | string | No | The mimeType of the attachment. Max length 256 | | idCardSource | query | string | No | The ID of a card to copy into the new card | | keepFromSource | query | enum: all, attachments, checklists, comments, customFields, due, ... | No | If using idCardSource you can specify which properties to copy over. all or comma-separated list of: attachments,checklists,customFields,comments,due,start,labels,members,start,stickers | | address | query | string | No | For use with/by the Map View | | locationName | query | string | No | For use with/by the Map View | | coordinates | query | string | No | For use with/by the Map View. Operation ID: put-cards-id.

Authentication: API key in the query (APIKey) or API key in the query (APIToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string | Yes | The ID of the Card | | name | query | string | No | The new name for the card | | desc | query | string | No | The new description for the card | | closed | query | boolean | No | Whether the card should be archived (closed: true) | | idMembers | query | string | No | Comma-separated list of member IDs | | idAttachmentCover | query | string | No | The ID of the image attachment the card should use as its cover, or null for none | | idList | query | string | No | The ID of the list the card should be in | | idLabels | query | string | No | Comma-separated list of label IDs | | idBoard | query | string | No | The ID of the board the card should be on | | pos | query | enum: top, bottom or number (float) | No | The position of the card in its list. top, bottom, or a positive float | | due | query | string (date) | No | When the card is due, or null | | start | query | string (date) | No | The start date of a card, or null | | dueComplete | query | boolean | No | Whether the status of the card is complete | | subscribed | query | boolean | No | Whether the member is should be subscribed to the card | | address | query | string | No | For use with/by the Map View | | locationName | query | string | No | For use with/by the Map View | | coordinates | query | string | No | For use with/by the Map View. Should be latitude,longitude | | cover | query | object | No | Updates the card's cover | Option | Values | About | |--------|--------|-------| | color | pink, yellow, lime, blue, black, orange, red, purple, sky, green | Makes the cover a solid color . | | brightness | dark, light | Determines whether the text on the cover should be dark or light. | url | An unsplash URL: https://images.unsplash.com | Used if making an image the cover. Only Unsplash URLs work. | idAttachment | ID of an attachment on the card | Used if setting an attached image as the cover. | | size | normal, full | Determines whether to show the card name on the cover, or below it. | brightness can be sent alongside any of the other parameters, but all of the other parameters are mutually exclusive; you can not have the cover be a color and an idAttachment at the same time. On the brightness options, setting it to light will make the text on the card cover dark: And vice versa, setting it to dark will make the text on the card cover light: |

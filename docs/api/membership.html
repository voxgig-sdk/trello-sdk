GET /enterprises/{id}/members/query

Operation ID: get-users-id.

Authentication: API key in the query (APIKey) or API key in the query (APIToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string | Yes | ID of the enterprise to retrieve. | | licensed | query | boolean | No | When true, returns members who possess a license for the corresponding Trello Enterprise; when false, returns members who do not. If unspecified, both licensed and unlicensed members will be returned. | | deactivated | query | boolean | No | When true, returns members who have been deactivated for the corresponding Trello Enterprise; when false, returns members who have not. If unspecified, both active and deactivated members will be returned. | | collaborator | query | boolean | No | When true, returns members who are guests on one or more boards in the corresponding Trello Enterprise (but do not possess a license); when false, returns members who are not. If unspecified, both guests and non-guests will be returned. | | managed | query | boolean | No | When true, returns members who are managed by the corresponding Trello Enterprise; when false, returns members who are not. If unspecified, both managed and unmanaged members will be returned. | | admin | query | boolean | No | When true, returns members who are administrators of the corresponding Trello Enterprise; when false, returns members who are not. If unspecified, both admin and non-admin members will be returned. | | activeSince | query | string | No | Returns only Trello users active since this date (inclusive). | | inactiveSince | query | string | No | Returns only Trello users active since this date (inclusive). | | search | query | string | No | Returns members with email address or full name that start with the search value. | | cursor | query | string | No | Cursor to return next set of results, use cursor returned in the response to query the next batch. |

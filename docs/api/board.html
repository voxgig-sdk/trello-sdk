create

POST /boards/

Operation ID: post-boards.

Authentication: API key in the query (APIKey) or API key in the query (APIToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | name | query | string | Yes | The new name for the board. 1 to 16384 characters long. | | defaultLabels | query | boolean | No | Determines whether to use the default set of labels. | | defaultLists | query | boolean | No | Determines whether to add the default set of lists to a board (To Do, Doing, Done). It is ignored if idBoardSource is provided. | | desc | query | string | No | A new description for the board, 0 to 16384 characters long | | idOrganization | query | string | No | The id or name of the Workspace the board should belong to. | | idBoardSource | query | string | No | The id of a board to copy into the new board. | | keepFromSource | query | enum: cards, none | No | To keep cards from the original board pass in the value cards | | powerUps | query | enum: all, calendar, cardAging, recap, voting | No | The Power-Ups that should be enabled on the new board. One of: all, calendar, cardAging, recap, voting. | | prefs_permissionLevel | query | enum: org, private, public | No | The permissions level of the board. One of: org, private, public. | | prefs_voting | query | enum: disabled, members, observers, org, public | No | Who can vote on this board. One of disabled, members, observers, org, public. | | prefs_comments | query | enum: disabled, members, observers, org, public | No | Who can comment on cards on this board. One of: disabled, members, observers, org, public. | | prefs_invitations | query | enum: members, admins | No | Determines what types of members can invite users to join. One of: admins, members. | | prefs_selfJoin | query | boolean | No | Determines whether users can join the boards themselves or whether they have to be invited. | | prefs_cardCovers | query | boolean | No | Determines whether card covers are enabled. | | prefs_background | query | enum: blue, orange, green, red, purple, pink, ... | No | The id of a custom background or one of: blue, orange, green, red, purple, pink, lime, sky, grey. | | prefs_cardAging | query | enum: pirate, regular | No | Determines the type of card aging that should take place on the board if card aging is enabled. One of: pirate, regular. |

Responses

200: Success
